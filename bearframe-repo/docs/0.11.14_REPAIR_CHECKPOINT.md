# Last Dispatch 0.11.14 recovery

Branch: `repair/last-dispatch-0.11.14`. Baseline: verified 0.11.11 release, through the 0.11.12 and 0.11.13 repair work. Earlier packs and history are retained.

The archive discovery path now populates native and survey-placed archive sites using site-appropriate resident pools. Saved claims prevent repeated visits from adding mobs. The fallback no longer runs its separate population roll for archive sites. Layout inspection found viable dry floor positions in all eleven small and district templates. Bedrock Dedicated Server exercised placement, population and rescan after removal for Frontier Ruin, Flooded Pump Bunker and Overgrown Colony. The probe placed templates directly to isolate occupancy from natural generation.

Native landmark spacing moved from 54 to 38 chunks. Natural occurrence and distance are still unverified. The change has no retrofit effect on generated chunks.

The selected RPG Loot 1.2.2 Java 1.21.1 data pack supplies the actual Simple Dungeon rare/epic weights (6:1) and Ancient City rare/epic/legendary weights (60:15:1). Bedrock tables now use those ratios in their equivalent gear pools with Bearframe item IDs and the existing overall gear-roll rate. No restricted Farfield or signature boss equipment was added to chests. The original pack's unique items, enchantment functions and full source-specific distribution are beyond this conversion.

The optional `tools/read_litematic.mjs` reads the exact uploaded Astro source without committing the third-party schematic. It decoded and counted all 35,961 occupied blocks, 238 palette states, and six block entities across the signed region. Actual Bedrock palette conversion, import and department furnishing are open.
