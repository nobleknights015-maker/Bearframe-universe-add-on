## Reproduce from the private 0.11.45 starter

Keep the supplied source pack and derived installers in the private handoff.
This branch contains the conversion code and reproducibility record.
Run from `bearframe-repo/tools` with Python, Pillow and NumPy. Use the
0.11.44 and 0.11.45 installers and the Nongko ZIP from the starter handoff.
The commands below use short filenames for the three input files.

```sh
python convert_field_cutter_01147.py base45.mcaddon rollback44.mcaddon nongko.zip 47.mcaddon
python rebuild_arsenal.py 47.mcaddon nongko.zip 49.mcaddon
python add_grid_boss_weapons.py 49.mcaddon nongko.zip 50.mcaddon
python redraw_inventory.py 50.mcaddon 51.mcaddon inventory.png
python redraw_log_pad.py 51.mcaddon 52.mcaddon log-pad.png
```

A full replay of these stages matched all 1,584 entries in the approved
installer byte-for-byte. ZIP metadata and entry ordering may affect the
outer ZIP checksum. The intermediate 0.11.48 appearance pass is superseded
by the rebuilt 0.11.49 models.
