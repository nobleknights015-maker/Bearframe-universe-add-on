# 0.11.16 station repair candidate

Base is the published 0.11.15 commit d8f676b791909bbf4dae9c7e6d9ceb37866e726d.
An occupied section without its saved marker is accepted when its blocks,
states and waterlogging match the packaged template. A mismatch stops transit
with the section ID in the server log. The repair leaves occupied blocks in
place. Blocked lift landings and chunk-load failures give the player a message.
An in-flight lift request uses the same per-player transit guard as the tablet.

All 135 Node tests passed. The installer verifier matched all 773 files and
18 held-item asset chains. A Bedrock Dedicated Server fixture cleared the first
section marker on an already built station and verified that transit's build
routine restored it. The fixture loaded the repair scripts over its existing
0.11.15 world. Android lift interaction, full interrupted construction and
real multiplayer remain to be tested.
