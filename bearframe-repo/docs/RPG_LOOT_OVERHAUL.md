# Native rarity loot expansion — 0.11.1 candidate

Mechanics inspired by RPG Loot (https://modrinth.com/datapack/rpg-loot): rarity tiers, unique boss equipment and source-dependent drops. Original RPGLoot (https://www.curseforge.com/minecraft/mc-mods/rpgloot) focuses on corpse inventories, which is not appropriate for this lightweight Bedrock expansion. Both are Java projects; no Java code or third-party assets were included. Download attempts were blocked by DNS. Uploaded Star Odyssey pack was inspected for visual style only; no pack textures copied or redistributed.

Twelve new weapons are native items, with original transparent 16x16 inventory textures, colored rarity names, damage values from 5 to 10, repairable durability on non-Legendary weapons and no durability component on Legendary weapons. Actual held rendering and unbreakability must be confirmed in Bedrock. Four general expedition weapons are weighted rewards from existing chest tables; four hostile mob loot tables receive a low probability of general gear. Eight boss-specific tables retain ordinary salvage and guarantee one signature weapon plus bonus salvage. No change to neutral Echo or common Grid loot tables. Existing chest loot pools remain intact. Drop odds apply each time a loot table is rolled, not to all chests in a structure. Previously opened chests are not retroactively refilled. No new armor, ranged weapon behavior, random affix rolls or scripted active abilities implemented in this checkpoint. All equipment is melee. Live Android/Bedrock testing still required.

The CI workflow packages version 0.11.1 in its isolated build workspace; source manifest versions remain as in 0.10.24. No old release file is overwritten.
