# 0.11.11 Faction classification

Shared registry covers 51 variants and 57 recognized entity identifiers, including aliases. Vanilla illagers and Ravagers count as Directorate; hostile humanoid replacements and Vex count as feral Echo variants; Warden and Creaking use the existing legacy machine visual replacements and count as Ghost Grid. Conditional mobs must have attacked a player or escalated; stabilized Echo Sentinels and peaceful units do not count. Ordinary wildlife and other add-on IDs are not classified. Existing Directorate-only contracts remain Directorate-only; local clearance accepts hostile Echo/Grid variants. New Field Log combat records distinguish individual variants and preserve historical totals without inventing past faction kills. Boss hunt credit and original quest IDs retained. No new mob models, behavior or spawn changes. Vanilla replacement labels added to en_US; live client language rendering and event attribution require Bedrock testing.
