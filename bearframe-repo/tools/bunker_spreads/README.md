# Bunker Spreads to Bearframe 0.11.20 local converter
Requires Python 3, numpy, scipy and Node.js. Original owner-supplied ZIP and exact 0.11.19 local candidate are inputs. Run:

`python run_conversion.py "Bunker Spreads.zip" Bearframe_The_Last_Dispatch_0.11.19_Integrated_Cities.mcaddon output.mcaddon`

Main connected complex extracted via source block palettes; sparse cells converted and tiled, native marker and staged runtime placement. No raw third-party world/structure files, player data, or original item inventories included in this tool. The converter emits intermediate source-derived arrays locally; do not commit them. See repository checkpoint for known conversion and live QA limitations.
