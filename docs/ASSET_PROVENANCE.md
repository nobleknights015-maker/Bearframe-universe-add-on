# Asset provenance

All model files, texture atlases, entity definitions, the schematic icon, the station layout and the repair script belong to this checkpoint. Procedural sources live under tools. Native vanilla identifiers supply most building blocks, lights, crafting results and the success sound.

The attached Infinity Sci-Fi resource pack is version 1.0.9 with minimum 1.18.0. Its manifest identifies a resources module only. The inspected ZIP has 2,043 entries, including 1,865 PNGs, 93 TGAs and eight JSON files. Sampled blocks use 32×32 art. It supplied reference palettes and was installed separately in a disposable compatibility world. Neither its resources nor the Bearframe visual reference images are redistributed.

Read the six faction reference sheets from the 4.10 source for later authored variants. Refer to REUSE_AUDIT.md for the original Starbound patterns.
